《一程山路》07 声音层试听台

全部程序化 WebAudio 合成，零音频文件。首次点击任意按钮即解锁 AudioContext（模拟微信 H5 手势解锁）。

① 环境音床（相位联动）——点下方相位按钮切换，听淡入淡出交叉过渡

昼床 = 车间金属声浪（车床嗡呜底噪 + 工友交谈嗡嗡层 + 随机事件：叮当敲击 / 嗒嗒嗒铆枪 / 嘶拉嘶拉锯床 / 锉刀 / 滋滋电焊 / 哎—哎—哎插齿机 / 远处吆喝），整床进厂房混响； 夜床 = 蝉群颤翼（三组窄带振翅）+ 蛐蛐远近两只 + 双层风（阵风起落）+ 夜气底噪 + 远犬。WEEK_SETTLE 归夜床并自动响电铃。

② UI 反馈音五件套

③ 循环结算音

④ 机制联动 A：偏离度 → 全局低通渐闷

偏离度：0

阈值取自 params.json：≥3(warning) 开始收窄 → ≥10(erase) 收至 ~650Hz。先切昼床再拖滑条对比最明显。

⑤ 机制联动 B：12kHz 耳鸣

常驻耳鸣：偏离度 ≥6(drift) 渐入、向 10 渐强——拖上面滑条到 6+ 可持续听到；回落即退。

⑥ 移动端适配自检

iOS 静音键是系统级硬开关，WebAudio 无法检测/绕过；兜底 = 所有声音可缺席不影响游玩。详见 design/INTEGRATION-NOTES.md。
